# Estructuras de datos y Algoritmos

Repositorio de guías prácticas de algoritmos y estructuras de datos en Java 21. Cada unidad incluye especificación y prompts; las unidades con código también incluyen soluciones y pruebas.

## Unidades

1. [Análisis de algoritmos](./unidad-1-analisis-de-algoritmos/) — búsqueda, comparación, inversión, matrices y Bubble Sort.
2. [Recursividad](./unidad-2-recursividad/) — diez problemas resueltos recursivamente.
3. [Algoritmos de ordenamiento](./unidad-3-ordenamiento/) — algoritmos clásicos, trazas y métricas.
4. [Pilas y colas con arreglos](./unidad-4-pilas-y-colas/) — estructuras LIFO/FIFO, colas lineales y circulares.
5. [Listas enlazadas simples](./unidad-5-listas-enlazadas/) — inserción, búsqueda, eliminación e inversión.
6. [Pilas y colas con listas enlazadas](./unidad-6-pilas-colas-listas-enlazadas/) — estructuras enlazadas, genéricos y simuladores.
